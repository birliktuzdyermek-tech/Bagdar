# Бағдар — Витрина

Статический сайт-презентация. Сессия 2 по `BAGDAR V2.md`. Работает без сервера и без интернета: записи, стили и скрипты лежат внутри сборки.

**Главное правило.** Всё, что движется на экране, проигрывается из файлов `replay` (контракт v1, `contracts/replay.schema.json`) и подписано «Запись прогона». Витрина не считает планы и ничего не дорисовывает.

## Запуск

```bash
cd showcase
npm ci
npm run dev        # http://localhost:5180
npm run build      # статическая сборка в showcase/dist, base "./" — открывается с любого адреса
npm run preview    # проверить сборку
```

Клавиши проигрывателя: пробел — пуск и пауза, ← → — минута, Shift — 10 минут, + − — скорость, P — режим проектора, Esc — снять выбор поезда.

## Записи

Список — `public/runs/index.json`, файлы — `public/runs/*.replay.json` или `*.replay.json.gz`. Новая запись подключается без правки кода: положить файл и добавить строку в список.

Записи снимает `tools/record.py`. Он запускает `SimulationRuntime` Ядра с планировщиком, делает настоящие шаги движка, проверяет результат моделью `Replay` из `contracts/export.py` и сжимает его:

```bash
python showcase/tools/record.py --id normal-42 --seed 42 --hours 4 --title "Штатное движение, утро"
python showcase/tools/record.py --id butterfly-42 --seed 42 --hours 4 --situation 15 \
  --title "Опоздание скорого № 2 на 15 минут" --delay 07:00 t2 15 "неисправность локомотива"
```

`--delay` — внешняя команда Ядру, та же, что `POST /api/events` с `train_delay`. Она отмечена на шкале и в шапке записи.

Кадр — каждые 20 секунд модели. Четыре часа весят около 13 МБ, после gzip около 0,6 МБ. Браузер распаковывает файл сам через `DecompressionStream`.

## Что готово (шаг 2 — проигрыватель)

- Схема участка на холсте: пункты, пути с занятостью, перегоны, поезда. Форма метки зависит от группы, статус показан обводкой и значком. Место решения вспыхивает.
- График движения: пунктир — действующий план из записи, сплошная — факт по кадрам. При смене плана нитки перетекают за 700 мс, изменённые подсвечены.
- Панели: время модели, планировщик, показатели с докручиванием чисел, индекс, карточка поезда, лента решений с уровнями A, B, C. Клик по событию перематывает к нему.
- Пауза, шесть скоростей, перемотка со шкалой меток, клавиатура, режим проектора, настройка «меньше движения», телефонный вид.

## Чего нет в формате replay (вопросы к Ядру)

- **Карточки решений.** В записи есть только событие `decision` с `card_id` и текстом действия. Причины, альтернативы и цены в у. е. нет, поэтому карточка «почему» не показывается.
- **Индекс.** `frames[].index` пока `null`, витрина пишет «индекс пока не рассчитан».
- **Сбои.** Физических сбоев в Ядре пока нет, поэтому волны и фронтов нет.
- **Пары «с Бағдаром и без».** Нет способа связать два прогона одного потока.
